# Last Archer Portable Environment Kit

All dimensions are meters. Every asset has a base-center root pivot and is exported as a separate binary GLB.
The files use flat-shaded geometry, simple colors, and no texture maps. Materials prefixed `AD_SURFACE_` are sponsor-ready.

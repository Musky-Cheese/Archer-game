# V2.5 dark anime city kit

This kit provides seven reusable, separate GLBs for the first city-block study. Each uses metre scale, a base-centre root, flat material colors and no texture files. See `manifest.md` for measurements and budgets.

The GLBs are directly usable in Three.js today. `blender-build-v2.5-city-kit.py` is the editable Blender recipe. Open `last-archer-v2.5-city-kit-source.blend` in Blender and run the recipe from the Scripting workspace to rebuild the objects and export matching GLBs in `individual-assets/`.

The `.blend` is a source starter copied from the prior environment kit because Blender was not available to this execution environment. It is intentionally paired with the full construction recipe; the recipe creates the Stage 3 geometry inside it before saving.
